Windows 桌面应用 · v0.1.3

让 opencode run
像守护进程一样持续迭代

OpenCodeLoop 为每个项目配置一条提示词，自动循环拉起 OpenCode，处理额度、限流、鉴权与会话冲突， 直到任务完成或达到你设定的上限。

免费 · MIT 许可 · 仅提醒更新，不自动下载

专注无人值守的细节

不只是循环执行命令，而是把无人值守会遇到的问题处理完整。

多任务守护

同时守护多个项目，逐任务启停、立即重启，查看轮数、退出码、本轮时长与实际模型。

会话闸门

发送前检测 TUI / 桌面端是否正在执行、是否还有排队消息，忙碌时等待空闲，避免插话。

错误分级恢复

额度不足等待恢复点，鉴权失败停止或切换备选模型，限流退避，端口冲突自动修复。

模型链与迭代

主力模型额度不足 / 限流 / 鉴权失败后按序顺延备选，解封后自动切回主力；支持持续迭代模式与轮数上限。

日志与诊断

全量输出落盘，应用内语义化展示 AI 文本、工具调用与错误；日志按任务过滤。

更新检测

启动时检查 GitHub Releases，发现新版本仅提醒，绝不自动下载或安装。

工作方式

  1. 配置任务 选择项目目录，填写提示词，指定会话策略与完成标记。
  2. 启动守护 自动拉起 opencode run；退出后按间隔重启，异常按类型恢复。
  3. 收尾交付 检测到完成标记（默认 DONE）后停止或进入下一轮迭代。 
# 每个任务独立守护
[默认任务] 第 3 轮启动 · deepseek/deepseek-flash
[PR-OSC]  第 21 轮启动 · glm-5.3-flash
[PR-OSC]  检测到会话正在运行，等待空闲…
[PR-OSC]  会话已空闲（上次结果：成功），开始发送
[默认任务] 输出中出现完成标记「DONE」

安装与使用

前置要求

本机已安装 OpenCode CLI，并在 PATH 中可用（或在设置中指定完整路径）。

  1. 下载安装包从 GitHub Releases 获取最新版本。
  2. 新建任务选择项目目录，调整提示词与会话策略。
  3. 启动守护最小化到托盘，等待任务完成。
从源码运行
git clone https://github.com/smoothwind/OpenCodeLoop.git
cd OpenCodeLoop
npm install
npm run dev
构建安装包
npm run dist
